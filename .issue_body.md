Enhance the game's UI and user experience with a focus on clarity, accessibility, and player feedback.

Summary
- Improve HUD visuals and layout.
- Add tooltips and contextual information for units, buildings, and actions.
- Add visible selection highlights and improved selection behavior.
- Improve HUD icons, progress bars, and log messages.
- Add basic accessibility improvements (keyboard navigation and colorblind-friendly palette option).

Why
These changes make the game easier to play, reduce confusion during gameplay, and prepare the UI for future features (sound, options, tutorials).

Proposed tasks
- HUD: refine layout, add icons for spice, carried, unit/building counts; improve fonts and spacing.
- Tooltips: show name/HP/capacity when hovering units or buildings.
- Selection: improve visual selection ring and support multi-select (shift+click) and box-select.
- Keyboard: add basic keyboard shortcuts (B = build barracks, T = train trooper, space = center on base).
- Accessibility: add a colorblind mode toggle in settings (simple CSS palette swap).
- Small UX touches: floating health numbers, improved log messages, and HUD notifications.

Acceptance criteria
- HUD visually improved and shows icons + clearer numbers.
- Hovering shows a non-blocking tooltip with name and HP.
- Selection visuals are clearer and multi-select works.
- Basic keyboard shortcuts implemented and documented in README.
- Colorblind mode toggle exists and visibly switches palette.
- Tests added for selection logic and tooltip content (unit tests).
- Roadmap and README updated to document features and shortcuts.

Notes
- Pure client-side change; no backend required.
- Keep changes conservative and test-driven; add tests in `tests/` for any new logic.
